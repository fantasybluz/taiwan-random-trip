# 台灣隨機旅行

搭火車的隨機旅行轉盤，分三層轉：**地區 → 縣市 → 車站**，轉到哪就去哪。像素風，手機、電腦都能用。

有兩個版本，上方可以切換：

| 版本 | 車站 | 網址 |
|---|---|---|
| 區間車 | 區間車、區間快有停的 240 站 | https://fantasybluz.github.io/taiwan-random-trip/ |
| 自強3000 | EMU3000 有停的 76 站 | https://fantasybluz.github.io/taiwan-random-trip/#emu3000 |

## 玩法

- 按轉盤中間的「發車」轉目前這一層，轉完自動換下一層的轉盤
- 「一次轉到車站」會把剩下的幾層一路轉完
- 地區和縣市不想交給轉盤決定，也可以在旁邊直接點
- 上方的步驟列可以點已經選好的那層，回去重選
- 轉到車站後會出一張「車票」：地址、區間車一天大約幾班停，附 Google 地圖和維基百科連結；
  班次太少的站會提醒先查回程
- 右上角可以關掉音效（記在這支手機上）
- 自強3000 版沒有停南投縣，轉盤上不會出現；只有一站的縣市（例如新竹縣只停湖口）轉到就直接帶出那一站
- 車票上的班次會列出兩種車各停幾班，一天不到一班的用一週算

地區照常見分法：北部（基北北桃竹竹）、中部（苗中彰投雲）、南部（嘉嘉南高屏）、東部（宜花東）。
每一層的每一格機率都一樣，所以站少的縣市（例如嘉義市只有 2 站）裡的車站比較容易被抽到。

## 像素風轉盤怎麼畫

- `src/lib/pixelWheel.ts`：畫布用低解析度（一個像素約 2 個 CSS px），每個像素算距離和角度決定顏色，
  再用 `image-rendering: pixelated` 放大。像素大小會配合 devicePixelRatio 取整數，每格才一樣大
- 轉動時不是旋轉整張圖（像素會變斜的菱形），而是每一幀照新角度重畫，像素永遠是正的
- 站名每個字都是正的，沿著半徑排；轉盤右半邊和下面改從內圈排起，才會由左到右、由上到下讀
- 字型是[俐方體 11 號（Cubic 11）](https://github.com/ACh-K/Cubic-11)，OFL 授權（`src/assets/fonts/OFL.txt`），
  字級用 12 的倍數最清楚；畫布上的字先用 12px 畫、切成全有或全無再放大，不會糊

## 車站資料

`src/data/stations.json` 由 `scripts/fetch-stations.mjs` 從[台鐵開放資料](https://ods.railway.gov.tw/)產生：

1. 「車站基本資料集」拿站名、英文站名、地址（縣市從地址前三個字取）
2. 抓接下來 7 天的「每日時刻表」，數每一站一週有幾班區間車、幾班自強3000 停（`weeklyStops`），兩種都沒停的站不收

時刻表用 `CarClass` 分車種：

| 版本 | CarClass | 說明 |
|---|---|---|
| 區間車 | 1131、1132 | 區間車、區間快；南迴線（枋山～康樂）的區間車在時刻表裡標成區間快 |
| 自強3000 | 110G、110H | 這兩種每一班的備註都寫著「騰雲座艙」，那是 EMU3000 才有的商務車廂 |

開放資料沒有直接寫哪一班是 EMU3000，所以用「騰雲座艙」對照。腳本每次都會檢查一遍，
有騰雲座艙卻不在 110G／110H（或反過來）就會印警告，代表台鐵改了車種代碼，要改 `TRAIN_TYPES.emu3000`。
110K、110M 的備註只有自由座、沒有騰雲座艙，看不出是哪種車，先不算。

目前（2026-10-12）區間車 240 站、自強3000 76 站。幾個要注意的地方：
- 兩種車都沒停而被排除的：臺北-環島、樹林調車場、枋野、南方小站、潮州基地、新馬
  （新馬這一週的時刻表都沒有車停）
- 平鎮（臨時站，2026-10-03 啟用）時刻表有、車站資料集還沒收錄，寫在腳本的 `EXTRA_STATIONS` 補上

更新資料：

```sh
npm run stations
npm test   # 檢查每站的縣市都有分到地區、每個版本的每個地區都有站
```

腳本遇到車站資料集裡沒有的站碼會印出警告並略過，要的話加到 `EXTRA_STATIONS`。

## 開發

```sh
npm install
npm run dev
npm run lint && npm run lint:css && npm test
npm run build
```

## 部署

GitHub Pages，推到 `main` 會跑 `.github/workflows/deploy.yml`（lint、測試、build 後部署）。
`vite.config.ts` 的 `base` 是 `/taiwan-random-trip/`，repo 名稱不一樣的話要一起改。
